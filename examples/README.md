# Examples

Runnable scripts a reader can execute against a working install, kept outside the
package because they are not part of the product.

Eight of the thirteen surveyed repositories have this directory, and the ones
that use it well share a habit: **each example is small enough to read in one
screen and does exactly one thing.** A directory of half-maintained demos is
worse than none — it is the first documentation to rot, and readers trust it
longest.
